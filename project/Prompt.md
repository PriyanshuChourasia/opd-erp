* [ ] Standing Instructions

Always follow this file whenever a new prompt is given, for every task in this repository.

## Rules

1. **Every prompt is a task.** For each new prompt (task), create a new markdown file inside `project/tasks/` before starting work.
2. **File naming:** `YYYY-MM-DD_task-<N>.md`, where `<N>` is the next sequential task number (check existing files in `project/tasks/` to find the last number used).
3. **File content — create at task start, update as work proceeds, finalize at completion:**
   - [ ] `# Task <N> — <short title>`
   - [ ] `Date: <YYYY-MM-DD>`
   - [ ] `Status: In Progress` (update to `Completed` / `Blocked` when applicable)
   - [ ] `## Task Given` — the exact prompt/request as given by the user.
   - [ ] `## Task Accomplished` — what was actually done, kept up to date as work progresses, finalized when the task completes.
   - [ ] `## Files Changed` — list every file created/modified/deleted, with a one-line note per file on what changed.
   - [ ] `## Notes` (optional) — blockers, deviations from the request, follow-ups needed.
4. **Task Given vs Task Accomplished must always both be present**, so any gap between what was asked and what was delivered is visible at a glance.
