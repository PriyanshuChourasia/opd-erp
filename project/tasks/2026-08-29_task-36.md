# Task 36 — Build the Dashboard UI

Date: 2026-08-29
Status: Completed

## Task Given

Build the Dashboard UI for the existing hospital/clinic management backend and frontend.

IMPORTANT:
- First inspect the existing frontend architecture, components, routing, styling system, API/service layer, authentication, and existing Dashboard page.
- Modify the existing Dashboard rather than creating a separate application or new architecture.
- Follow the existing design system, typography, spacing, colors, icons, components, and coding conventions.
- Do not modify unrelated pages or functionality.
- Do not add fake backend APIs. If APIs already exist, use them. If dashboard APIs are not available yet, create the UI with clearly separated mock/static data so it can be connected later.
- Make the dashboard responsive for desktop, tablet, and mobile.
- Keep the current sidebar/navigation structure.

DASHBOARD GOAL:

The Super Admin Dashboard should provide a quick overview of the entire clinic/hospital.

HEADER:
Show:
- "Welcome, Super Admin"
- Short subtitle: "Here's what's happening at the clinic today."
- Current date
- Notification icon
- User/profile menu

SUMMARY CARDS:
Create clean dashboard cards for:
1. Today's Appointments — Total appointments today, small indication of completed/pending
2. Patients in Queue — Current patients waiting, queue status
3. Total Patients — Total registered patients, optional growth/change indicator
4. Doctors — Total active doctors, doctors currently available today
5. Today's OPD Visits — Number of OPD visits today, completed vs waiting
6. Pending Prescriptions — Number of prescriptions requiring attention
7. Outstanding Bills — Total outstanding amount
8. Low Stock Medicines — Number of medicines below stock threshold

MAIN DASHBOARD SECTIONS:
1. TODAY'S APPOINTMENTS — Table with patient name, doctor, department, time, status, action
2. TODAY'S QUEUE — Queue number, patient name, doctor, waiting time, status; current patient prominent
3. APPOINTMENT OVERVIEW — Chart showing appointment stats for current week
4. OPD OVERVIEW — Today's visits, completed consultations, waiting patients, avg waiting time
5. DOCTOR AVAILABILITY — Doctor name, specialization, department, available/unavailable, appointment count
6. RECENT PATIENTS — Recently registered/visited patients with details
7. REVENUE OVERVIEW — Revenue chart with Today/Week/Month filters
8. LOW STOCK MEDICINES — Medicines requiring attention
9. QUICK ACTIONS — Buttons navigating to existing routes

SUPER ADMIN SPECIFIC:
- Clinic Overview: Total Doctors, Staff, Departments, Active Users, Patients, Medicines
- Recent Activity feed with timestamps

DESIGN:
- Professional, clean, modern, medical/healthcare focused
- Cards with subtle borders/shadows, sufficient whitespace
- No excessive gradients, large graphics, unnecessary animations
- Responsive: Desktop 4-col cards, Tablet 2-col, Mobile single-col
