## Notes

- **DB:** admin-api now reads/writes MySQL `opdadmin` (`DB_PASSWORD=priyanshuadmin`). Running `php artisan migrate:fresh --seed` will rebuild everything.
- **API base:** with `VITE_API_BASE` set, the browser calls `https://admin-api.test/api` directly (cross-origin if admin-ui is on another host). The API's default Laravel CORS (`allowed_origins=*`, no credentials) permits `Authorization: Bearer` requests; if you move to credentialed/cookie flows later, publish `config/cors.php` and tighten origins.
- **APP_URL caveat:** `APP_URL` is only used for URL generation (e.g. `route()` redirects). Keeping `/api` in it is fine for this app since routes already carry the `api/` prefix and JWT issuer uses the request URL — but if you later add `route()`-based redirects/email links they will be `https://admin-api.test/api/api/…`; the host-root (`https://admin-api.test`) is the conventional value.
