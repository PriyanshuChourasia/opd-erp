# Task 8 — Users module in admin-api + Users route in admin-ui

Date: 2026-08-29
Status: Completed

## Task Given

> create users route in Ui and User Module in admin-api, follow /project/Prompt.md

## Task Accomplished

- **admin-api: new `User` nwidart module** (`Modules/User`) exposing JWT-protected CRUD against the `users` table:
  - `GET /api/users?page&limit&search` → `{ data, meta: { total, page, limit, totalPages } }` (search on name/email, bounded limit).
  - `POST /api/users` (201) with `StoreUserRequest` (name, unique email, min-8 password).
  - `GET /api/users/{id}` and `PUT /api/users/{id}` (`UpdateUserRequest` — partial updates, blank password = unchanged, unique email ignores self).
  - `DELETE /api/users/{id}` → 204; blocked with 422 if the target is the currently authenticated user.
  - Routes registered via `UserServiceProvider` (RouteServiceProvider-style), `modules_statuses.json` updated, composer merge re-autoloaded (`Modules/*/composer.json`).
- **admin-ui: Users feature + page.**
  - `src/features/users/` data layer: `interface.ts`, `schema.ts` (zod), `api.ts` (list/create/update/delete), `hooks.ts` (TanStack Query query + mutations with toast + cache invalidation).
  - New route `/_admin/users` with a data table (cards/skeleton/empty states), debounced search, pagination ("Page X of Y · N users", Previous/Next), per-row actions menu (Edit / Delete with confirm), and a create/edit dialog using react-hook-form + zod + shadcn `Field*` primitives.
  - Sidebar: "Users" is now a real link (`/users`, active-state aware); only "Roles & permissions" and "Audit logs" remain coming-soon placeholders.
  - Added shadcn components via CLI: `table`, `dialog`, `dropdown-menu`, `badge`.
- **Verified:**
  - API end-to-end (curl): login → list (meta correct) → create (id) → show → update (rename) → search → duplicate email 422 → self-delete 422 → delete 204 → unauthenticated 401; pagination page/limit respected.
  - UI: `vite build` regenerated `routeTree.gen.ts` (`/users` code-split chunk), `tsc --noEmit` clean, ESLint clean, dev-server transforms load the users page/hooks/dialog without errors.
