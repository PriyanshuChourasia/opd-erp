## Filter Logic

### Default behavior (no paymentStatus param)
```sql
WHERE status IN ('PENDING', 'PARTIAL')
  AND createdAt >= :from AND createdAt < :to
  AND deletedAt IS NULL
```

### With paymentStatus param
```sql
WHERE status = :paymentStatus
  AND createdAt >= :from AND createdAt < :to
  AND deletedAt IS NULL
```

## Doctor Name Resolution

Doctor names are resolved via `getDoctorNameMap()` which:
1. Collects all doctorIds from the bill query results
2. Batch-queries `User WHERE userableType = 'Doctor' AND userableId IN (...)`
3. Returns a Map<doctorId, "Dr. firstName lastName">
