# TASK 103 — Create Outstanding Payment Report UI

## Summary

Created the frontend Outstanding / Pending Payment Report page with filters, summary cards, aging analysis, and detailed invoice table.

## Features

### Filters
| Filter | Options |
|--------|---------|
| Quick Date Range | Today, This Week, This Month, Last 90 Days |
| Custom Date Range | From/To date pickers |
| Doctor | Dropdown populated from API |
| Payment Status | All, Pending, Partial, Paid, Cancelled, Refunded |

### Summary Cards
| Card | Value |
|------|-------|
| Total Outstanding | Sum of pending amounts (amber) |
| Total Billed | Sum of total amounts |
| Total Paid | Sum of paid amounts (green) |
| Collection Rate | Paid / Billed percentage |

### Aging Analysis
Four buckets: 0-30 days, 31-60 days, 61-90 days, 90+ days — showing count and pending amount per bucket.

### Status Breakdown
Shows count and pending amount for each payment status.

### Detailed Table
| Column | Data |
|--------|------|
| Patient | Name + phone |
| Appointment | ID (truncated) |
| Doctor | Name |
| Invoice | Invoice number |
| Total Amount | ₹ formatted |
| Paid | ₹ formatted (green) |
| Pending | ₹ formatted (amber) |
| Status | Badge with color |
| Appt. Date | YYYY-MM-DD |
| Invoice Date | Locale date |

### States
- Loading: Skeleton cards + table
- Error: Red error card
- Empty: "All invoices are fully paid" message
- Pagination: Previous/Next with page info
