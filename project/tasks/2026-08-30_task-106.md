# TASK 106 — Add Daily OPD Summary Export

## Summary

Added PDF and Excel export functionality to the Daily OPD Summary report page.

## Export Architecture

Reuses the existing application patterns:
- **Excel**: `xlsx` library — `XLSX.utils.json_to_sheet()` + `XLSX.writeFile()`
- **PDF**: `html2pdf.js` — Dynamic import, creates HTML element, converts to PDF via `html2pdf().set().from().save()`

## Excel Export

Creates a multi-sheet workbook:

| Sheet | Columns |
|-------|---------|
| Summary | Metric, Value |
| By Status | Status, Count, Percentage |
| By Type | Type, Count, Percentage |
| Doctor Performance | Doctor ID, Appointments, Completed, Revenue |
| Hourly Distribution | Hour, Appointments |

Filename: `daily-opd-summary_YYYY-MM-DD.xlsx` or `daily-opd-summary_YYYY-MM-DD_to_YYYY-MM-DD.xlsx`

## PDF Export

Generates a formatted HTML document with tables:
1. Appointments Overview (all KPIs from the UI)
2. Revenue (all revenue metrics from the UI)
3. By Status (status breakdown)
4. By Type (type breakdown)
5. Doctor Performance (doctor table)
6. Hourly Distribution (hourly table)

Filename: `daily-opd-summary_YYYY-MM-DD.pdf`

## UI Changes

Added two export buttons next to the date range picker:
- **Excel** button with Download icon
- **PDF** button with Download icon
- Both disabled when no data or loading
