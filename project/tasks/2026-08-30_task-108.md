# TASK 108 — Add Revenue Collection Export

## Summary

Added PDF and Excel export functionality to the Revenue / Collection Report page.

## Implementation

### Data Strategy

The report is paginated (50/page). For export, a separate query fetches ALL records with `limit=10000`:

```typescript
const exportQuery = useQuery({
  queryKey: ["reports", "revenue-collection-export", from, to],
  queryFn: () => fetchRevenueCollectionReport(from, to, undefined, undefined, undefined, 1, 10000),
  staleTime: 30_000,
  enabled: false, // Only fetch on export click
});
```

The query is refetched on each export click via `exportQuery.refetch()`.

### Excel Export

Creates a single-sheet workbook with all 14 columns matching the table:

| Column | Field |
|--------|-------|
| Date | `row.date` |
| Appointment | `row.appointmentId` |
| Patient | `row.patientName` |
| Doctor | `row.doctorName` |
| Registration Fee | `row.registrationFee` |
| Consultation Fee | `row.consultationFee` |
| Other Amount | `row.otherAmount` |
| Total Amount | `row.totalAmount` |
| Amount Paid | `row.amountPaid` |
| Amount Pending | `row.amountPending` |
| Payment Method | `row.paymentMethod` |
| Transaction/Reference Number | `row.transactionReference` |
| Invoice Number | `row.invoiceNumber` |
| Payment Status | `row.paymentStatus` |

Filename: `revenue-collection_YYYY-MM-DD_to_YYYY-MM-DD.xlsx`

### PDF Export

Generates a landscape A4 PDF with:
- Title and date range header
- Table with all 14 columns
- Totals row at the bottom (sums of all numeric columns)
- Column headers exactly match the UI table headers

Filename: `revenue-collection_YYYY-MM-DD_to_YYYY-MM-DD.pdf`

## UI Changes

Added two export buttons next to the date range picker:
- **Excel** button with Download icon
- **PDF** button with Download icon
- Always available (no disabled state needed since the query fetches all records on click)
