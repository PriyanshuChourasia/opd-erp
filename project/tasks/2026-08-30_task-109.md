# TASK 109 — Add Outstanding Payment Export

## Summary

Added PDF and Excel export functionality to the Outstanding / Pending Payment Report page.

## Implementation

### Data Strategy

The report is paginated (50/page). For export, a separate query fetches ALL records with `limit=10000`:

```typescript
const exportQuery = useQuery({
  queryKey: ["reports", "outstanding-payments-export", from, to, doctorId, paymentStatus],
  queryFn: () => fetchOutstandingPayments(from, to, doctorId, patientId, paymentStatus, 1, 10000),
  staleTime: 30_000,
  enabled: false,
});
```

The query is refetched on each export click via `exportQuery.refetch()`. This ensures only the currently filtered results are exported.

### Excel Export

Creates a single-sheet workbook with all 10 columns matching the table:

| Column | Field |
|--------|-------|
| Patient | `row.patientName` |
| Appointment | `row.appointmentId` |
| Doctor | `row.doctorName` |
| Invoice | `row.invoiceNo` |
| Total Amount | `row.totalAmount` |
| Paid Amount | `row.paidAmount` |
| Pending Amount | `row.pendingAmount` |
| Payment Status | `row.status` |
| Appointment Date | `row.appointmentDate` |
| Invoice Date | `new Date(row.createdAt).toLocaleDateString()` |

Filename: `outstanding-payments_YYYY-MM-DD_to_YYYY-MM-DD.xlsx`

### PDF Export

Generates a landscape A4 PDF with:
- Title and date range header
- Table with all 10 columns
- Totals row at the bottom (sums of Total Amount, Paid Amount, Pending Amount)
- Column headers exactly match the UI table headers

Filename: `outstanding-payments_YYYY-MM-DD_to_YYYY-MM-DD.pdf`
