### Field Summary

| Category | Fields | Required |
|----------|--------|----------|
| Anthropometric | Height, Weight, BMI (auto) | 0 required |
| Vital Signs | Temperature, Pulse, Systolic BP, Diastolic BP, SpO₂, Resp Rate | 0 required |
| Clinical | Medical Status | 0 required |
| **Total editable fields** | **9** | **0 required** |
| **Total display fields** | **1** (BMI) | — |

**Design rationale:** All fields are optional because vitals are partial — a nurse might only record BP and pulse during a quick check. The backend already handles this gracefully (all fields nullable). BMI auto-calculates when both height and weight are provided.
