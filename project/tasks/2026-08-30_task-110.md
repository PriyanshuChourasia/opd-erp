## Fixes Applied

### Fix 1: Revenue/Collection — Doctor Name Resolution

**Issue:** `doctorName` showed `appt.doctor?.specialization` (e.g., "Cardiology") instead of the actual doctor name (e.g., "Dr. John Smith").

**Fix:** Added `getDoctorNameMap()` call to resolve doctor names via the polymorphic User link, same pattern used in Outstanding Payments.

**File:** `apps/api/src/reports/reports.service.ts`

```diff
+ const doctorIds = appointments.map(a => a.doctorId).filter(...);
+ const doctorNameMap = await getDoctorNameMap(this.prisma, doctorIds);
  ...
- doctorName: appt.doctor?.specialization ?? 'Unknown',
+ doctorName: doctorNameMap.get(appt.doctorId) ?? appt.doctor?.specialization ?? 'Unknown',
```

### Fix 2: Revenue/Collection — Export Headers Match UI

**Issue:** Excel export used full column names (e.g., "Registration Fee") while UI table used abbreviated headers (e.g., "Reg. Fee").

**Fix:** Updated Excel export headers to match UI table headers exactly.

**File:** `apps/clinic-ui/src/modules/reports/components/revenue-collection-page.tsx`

```diff
- "Registration Fee": row.registrationFee,
+ "Reg. Fee": row.registrationFee,
```

### Fix 3: Doctor-wise OPD — Total Patients Double-Counting

**Issue:** `totalPatients` in the summary summed per-doctor unique patient counts, double-counting patients who saw multiple doctors in the same period.

**Fix:** Added a global `allUniquePatientIds` Set that tracks all unique patient IDs across all doctors, then used its size for the summary.

**File:** `apps/api/src/reports/reports.service.ts`

```diff
+ const allUniquePatientIds = new Set<string>();
  ...
  docData.uniquePatients.add(appt.patientId);
+ allUniquePatientIds.add(appt.patientId);
  ...
- totalPatients: report.reduce((sum, d) => sum + d.uniquePatients, 0),
+ totalPatients: allUniquePatientIds.size,
```
