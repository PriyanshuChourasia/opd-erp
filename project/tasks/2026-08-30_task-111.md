# TASK 111 — Add Allergy Search/Select to New Appointment Left Grid

## Summary

Added an Allergy search/select field to the left column of the New Appointment page, allowing users to search for and select patient allergies.

## Changes Made

### 1. Import `fetchAllergies` API function

Added `fetchAllergies` to the imports from `@/lib/api`.

### 2. Add allergy search state

Added `allergySearchQuery` and `allergySearchOpen` state variables.

### 3. Add allergy search query

Added a React Query hook to fetch allergies from the API:

```typescript
const allergyResults = useQuery({
  queryKey: ["allergies", "search", allergySearchQuery],
  queryFn: () => fetchAllergies({ search: allergySearchQuery || undefined, limit: 20 }),
  enabled: allergySearchOpen && allergySearchQuery.trim().length >= 1,
});
```

### 4. Add allergy UI to left column

Added after the Notes field, with:

- **Selected allergies display**: Red badges with X button to remove
- **Search input**: With search icon, searches via API
- **Dropdown results**: Shows matching allergies with name, severity, and category
- **Add custom**: If search doesn't match existing allergies, offers to add as custom text
