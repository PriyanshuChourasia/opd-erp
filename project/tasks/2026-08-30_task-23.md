## Task Accomplished

The Book & Pay flow **already works correctly**. No changes needed.

### Current Flow

```
User clicks "Book & Pay"
  → setPaymentSheetOpen(true)
  → PaymentSheet opens
    → User selects payment method (CASH/CARD/UPI/CHEQUE/OTHER)
    → User optionally enters discount, tax, notes
    → User clicks "Confirm & Book"
      → bookAndPayMutation.mutate(payload)
        → createAppointment() — creates appointment
        → checkoutAppointment() — creates Bill + BillItems
      → on success: invalidate queries → toast → navigate back
```

### PaymentSheet Component (`payment-sheet.tsx`)

- **Payment method grid**: CASH, CARD, UPI, CHEQUE, OTHER (with icons)
- **Discount input**: Number, min 0, max subtotal
- **Tax input**: Number, min 0
- **Notes textarea**: Optional
- **Totals breakdown**: Subtotal → Discount → Tax → Net Total
- **Actions**: Cancel, "Confirm & Book" (disabled during pending)

### Backend Flow

1. `POST /appointments` — creates Appointment (status: SCHEDULED)
2. `POST /appointments/:id/checkout` — creates Bill + BillItems
   - Bill: subtotal, discount, tax, total, paymentMethod, notes
   - BillItems: CONSULTATION (appointment.amount) + REGISTRATION (if > 0)
