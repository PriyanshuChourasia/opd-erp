## Task Given

Connect the Card payment modal fields to the payment API. When Card is selected:
- Capture the entered invoice/transaction number
- Submit it with the payment
- Persist the payment correctly
- Update payment status according to existing flow
- Handle success and failure states

## Task Accomplished

The Card payment flow was fully implemented in TASK 26. Verified the complete chain:

### Card Payment Flow

```
User selects Card
  → Reference Number input appears
  → User enters transaction/invoice number
  → User clicks "Confirm & Book"
    → bookAndPayMutation.mutate(payload)
      → createAppointment() → POST /appointments
      → checkoutAppointment(id, {
          paymentMethod: "CARD",
          referenceNumber: "TXN-12345",
          discount: ...,
          tax: 0,
          notes: ...
        })
      → POST /appointments/:id/checkout
        → Bill created with paymentMethod: "CARD", referenceNumber: "TXN-12345"
        → Bill.status = "PENDING" (default)
    → onSuccess: invalidate queries → toast → navigate
    → onError: toast.error(extractApiError)
```

### Success/Failure Handling

| State | Behavior |
|-------|----------|
| Loading | Button shows "Processing...", disabled |
| Success | Toast "Appointment booked and paid successfully", queries invalidated, navigates back |
| Error | Toast with API error message |

### Payment Status

- Bill created with `status: "PENDING"` (default) — same as all other payment methods
- Payment status tracked via `appt.bill` relation (existing flow)
