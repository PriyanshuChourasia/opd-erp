# Task 31 — Implement invoice generation for remaining payment

**Status:** Complete
**Date:** 2026-08-30

## Task Given

Update the Book & Pay flow so that if the appointment amount/payment remains unpaid after the payment attempt, an invoice is generated.

## Task Accomplished

### Problem

Previously, all Bills were created with `status: "PENDING"` regardless of how much was paid. There was no way to track actual payment vs remaining balance.

### Solution

Added `paidAmount` field to Bill and derived payment status from it.

### Payment Status Logic

```
if (no bill)           → "Unpaid" (amber badge + Generate Invoice button)
if (bill exists)
  if (paidAmount >= total) → "Paid" (green badge)
  if (paidAmount < total)  → "Partial" (amber badge)
```

### Backend Checkout Logic

```typescript
const paidAmount = dto.paidAmount ?? total;  // defaults to full payment
const status = paidAmount >= total ? 'PAID' : 'PENDING';
```

### Scenarios
