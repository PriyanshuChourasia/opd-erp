## UPI-Specific Flow

```
User clicks "Book & Pay"
  → PaymentSheet opens
  → User selects "UPI"
  → Reference Number input appears (same as Card)
  → User enters "UPI-TXN-789"
  → User clicks "Confirm & Book"
    → payload: {
        paymentMethod: "UPI",
        referenceNumber: "UPI-TXN-789",
        discount: 0,
        tax: 0,
        paidAmount: 600,
        notes: ""
      }
    → createAppointment() → Appointment created
    → checkoutAppointment() → Bill created with:
        - paymentMethod: "UPI"
        - referenceNumber: "UPI-TXN-789"
        - status: "PAID"
```

## Same as Card, Different Method

UPI and Card share the same reference number field and payment flow. Only `paymentMethod` differs in the Bill record.
