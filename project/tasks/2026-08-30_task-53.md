## Patient-to-Vitals Relationship

- One Patient → Many PatientVitals (1:N)
- `patientId` FK to Patient (required)
- `appointmentId` FK to Appointment (optional, SET NULL on delete)

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/patient-vitals` | List all (paginated) |
| GET | `/patient-vitals/latest/:patientId` | Get latest for patient |
| GET | `/patient-vitals/range/:patientId` | Get by date range |
| GET | `/patient-vitals/:id` | Get one by ID |
| POST | `/patient-vitals` | Create new vitals record |

## Service Methods

## What Exists vs What's Missing

| Feature | Status |
|---------|--------|
| Create vitals | ✅ Full (POST endpoint + UI modal) |

| Read vitals history | ✅ Full (paginated endpoint) |

## What Needs to Change

To support edit/update and delete:
1. Add `@Patch(':id')` endpoint to controller
2. Add `update(id, dto)` method to service
3. Add `@Delete(':id')` endpoint to controller
4. Add `remove(id)` method to service
5. Add `updatePatientVitals()` and `deletePatientVitals()` to frontend API
6. Add edit/delete UI components (buttons, confirmation dialogs)
