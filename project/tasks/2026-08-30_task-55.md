# Task 55 — Add new patient vitals recording

**Status:** Already Implemented (TASK 54)
**Date:** 2026-08-30

## Task Given

Update the Patient Vitals interface so a user can record a new vitals record for the selected patient.

## Verification

The vitals recording flow was fully implemented in TASK 54.

### Flow Trace

```
User clicks HeartPulse icon in patient table
  → setVitalsPatient(patient)
  → setVitalsSheetOpen(true)
  → Vitals Sheet opens with patient name

User fills vitals form
  → Height, Weight, Temperature, Pulse
  → Systolic/Diastolic BP, SpO₂, Resp Rate
  → Medical Status (dropdown)

User clicks "Record Vitals"
  → vitalsMutation.mutate()
    → createPatientVitals({ patientId, ...vitals })
    → POST /patient-vitals
  → onSuccess: toast "Patient vitals recorded" → close sheet
  → onError: toast error
```
