# Task 56 — Always fetch current vitals

**Status:** Already Implemented
**Date:** 2026-08-30

## Task Given

Update Patient Vitals retrieval logic so the interface always fetches the patient's current/latest vitals from the backend.

## Verification

### Current Fetch Logic (new-appointment-page.tsx)

```typescript
const vitalsQuery = useQuery({
  queryKey: ["patientVitals", "latest", form.patient?.id],
  queryFn: () => fetchPatientVitalsLatest(form.patient!.id),
```

- ✅ Refetches on query invalidation

### Backend findLatest (patient-vitals.service.ts)

```typescript
async findLatest(patientId: string) {
  const vitals = await this.prisma.patientVitals.findFirst({
    where: { patientId },
    orderBy: { recordedAt: 'desc' },  // ← most recent first
    ...
  });
  return vitals ?? null;
}
```

- ✅ Returns the most recently recorded vitals
- ✅ No soft-delete concept in PatientVitals model (no `deletedAt` field)
- ✅ All records are active
