# Task 58 — Add vitals delete button with soft delete

**Status:** Complete

## Task Given

- Ask for confirmation before deletion
- Soft delete (no physical removal)

## Delete Button Behavior

```
Patient Vitals  [Delete] [Add]
                 ↓ click
"Delete this vitals record?" (confirm dialog)
                 ↓ OK
DELETE /patient-vitals/:id
  → Sets deletedAt = new Date()
  → Invalidates vitals queries
  → Toast "Vitals deleted"
  → Vitals grid hides (no more records)
```
