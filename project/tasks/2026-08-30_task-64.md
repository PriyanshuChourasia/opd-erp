## Address Data Flow

```
User fills address form
  → "Register Patient" clicked
    → createPatient() → POST /patients
    → submitAddress(patientId) → createAddress({
        addressLine1, addressLine2, landmark, city, district,
        state, country, postalCode,
        addressableType: "Patient",
        addressableId: patientId
      })
    → POST /addresses
```
