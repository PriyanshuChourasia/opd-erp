## Standard Soft-Delete Design

### 1. Database (Prisma Schema)

```prisma
model Example {
  id          String    @id @default(uuid())
  // ... existing fields ...

  // Soft-delete fields
  deletedAt   DateTime?
  deletedById String?
  deletedBy   User?     @relation("ExampleDeleted", fields: [deletedById], references: [id])

  // Audit fields (existing pattern)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  createdById String?
  updatedById String?
  createdBy   User?     @relation("ExampleCreated", fields: [createdById], references: [id])
  updatedBy   User?     @relation("ExampleUpdated", fields: [updatedById], references: [id])

  @@index([deletedAt])
}
```

    const existing = await this.findOne(id);  // ← Validates exists + not deleted

      where: { id },

        deletedAt: new Date(),

      },
    });
  }
}

### 4. Controller Pattern

```typescript
@Controller('examples')
export class ExampleController {
  constructor(private readonly service: ExampleService) {}

  @Delete(':id')
  @Permissions('delete:examples')
  remove(@Param('id') id: string, @Req() req: { user: { id: string } }) {
    return this.service.remove(id, req.user.id);  // ← Pass userId
  }
}
```

## Conventions Summary

| Aspect | Convention |
|--------|------------|
| Field names | `deletedAt DateTime?`, `deletedById String?` |
| Relation name | `ModelDeleted` (e.g., `PatientDeleted`) |
| Query filter | `{ deletedAt: null }` on all queries |
| Delete method | `remove(id, deletedById?)` |
| Controller | `@Delete(':id')` with `@Req() req: { user: { id: string } }` |
| Error handling | `NotFoundException` if not found or already deleted |
| History | Record preserved in DB, never physically deleted |
| Index | `@@index([deletedAt])` for query performance |
