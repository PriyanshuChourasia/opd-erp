### Backend Service

| What | Before | After |
|------|--------|-------|
| `findAll` | `where.isActive = true` | `where.deletedAt = null` |
| `findOne` | `findUnique({ where: { id } })` | `findFirst({ where: { id, deletedAt: null } })` |
| `remove(id)` | `update({ isActive: false })` | `update({ isActive: false, deletedAt, deletedById })` |

### Backend Controller

| What | Before | After |
|------|--------|-------|
| `remove` | `remove(id)` | `remove(id, req.user.id)` |

## Soft-Delete Flow

```
DELETE /patients/:id
  → controller: remove(id, req.user.id)
    → service: findOne(id) — validates exists + not deleted
    → service: update({ isActive: false, deletedAt: new Date(), deletedById: userId })
    → Patient record preserved with soft-delete metadata
```

## Query Filtering

```
findAll: WHERE deletedAt IS NULL AND ...
findOne: WHERE id = ? AND deletedAt IS NULL
```
