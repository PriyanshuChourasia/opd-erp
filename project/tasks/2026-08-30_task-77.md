### How Soft-Delete Works

```
DELETE /module/:id
  → Controller: req.user.id extracted from JWT
  → Service: remove(id, userId)
    → Sets deletedAt = new Date()
    → Sets deletedById = userId
    → Record preserved in database

GET /module
  → Service: findAll()
    → WHERE deletedAt IS NULL
    → Deleted records excluded from response

GET /module/:id
  → Service: findOne(id)
    → WHERE id = ? AND deletedAt IS NULL
    → Deleted records return 404
```

### Soft-Delete Implementation Evidence

```typescript
// All modules now soft-delete instead of physical delete
async remove(id: string, deletedById?: string) {
  await this.findOne(id);
  return this.prisma.model.update({
    where: { id },
    data: {
      deletedAt: new Date(),      // ← Timestamp
      deletedById: deletedById ?? null,  // ← User who deleted
    },
  });
}
```
