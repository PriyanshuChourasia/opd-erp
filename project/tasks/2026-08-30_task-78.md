## Remaining Hard-Delete Operations (Intentional)

| Module | Reason for Hard-Delete |
|--------|------------------------|
| **Roles** | System configuration - roles are referenced by users; deleting a role would orphan users |
| **Permissions** | System configuration - permissions are referenced by roles; deleting would break authorization |
| **Sidebar Config** | System configuration - menu items are assigned to roles; deleting would break navigation |
| **Doctor Departments** | Junction table - links doctors to departments; deleting removes the assignment |
| **Doctor Specializations** | Junction table - links doctors to specializations; deleting removes the assignment |
| **Queue** | Transient data - queue entries are temporary; historical data not needed |
| **Prescription Templates** | Templates - users create/delete templates; history not required |
| **Employee Schedules** | ⚠️ Has deletedAt field but service still uses physical DELETE (marked READ-ONLY) |
