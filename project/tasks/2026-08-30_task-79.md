## 10. SUMMARY DASHBOARD METRICS

### Quick KPIs for Dashboard

| KPI | Calculation | Timeframe |
|-----|-------------|-----------|
| Today's Appointments | COUNT(Appointments WHERE date = TODAY) | Real-time |
| Today's Revenue | SUM(Bills.total WHERE date = TODAY) | Real-time |
| Patients in Queue | COUNT(QueueEntry WHERE status IN ['WAITING', 'IN_PROGRESS']) | Real-time |
| Average Wait Time | AVG(checkedInAt - createdAt) for today | Real-time |
| Collection Rate | SUM(paidAmount) / SUM(total) * 100 | Daily/Weekly/Monthly |
| Cancellation Rate | COUNT(CANCELLED) / COUNT(Total) * 100 | Daily/Weekly/Monthly |
| No-show Rate | COUNT(NO_SHOW) / COUNT(Total) * 100 | Daily/Weekly/Monthly |
| New Patients Today | COUNT(DISTINCT patientId WHERE appointment = first) | Daily |
| Revenue per Doctor | SUM(revenue) / COUNT(DISTINCT doctorId) | Daily/Weekly/Monthly |
| Pending Dues | SUM(total - paidAmount) WHERE status = 'PENDING' | Point-in-time |

## DATE RANGE SUPPORT

All reports should support:
- **Daily**: Single day view with hourly breakdown
- **Weekly**: Monday-Sunday or custom week
- **Monthly**: Calendar month or custom 30-day period
- **Custom Range**: User-defined start and end date
- **Comparison**: Previous period comparison (day-over-day, week-over-week, month-over-month)

---

## EXPORT FORMATS

All reports should support:
- **On-screen**: Interactive table with sorting/filtering
- **PDF**: Formatted report for printing/sharing
- **Excel/CSV**: Data export for further analysis
- **Email**: Scheduled report delivery (future enhancement)

## TECHNICAL NOTES

- Reports should use the existing Prisma database queries
- Aggregate functions (COUNT, SUM, AVG) should be calculated at the database level
- Date filtering should use the application's existing timezone handling
- Soft-deleted records (deletedAt IS NOT NULL) should be excluded from all reports
- Reports should respect role-based access control (e.g., doctors see only their data)
- Performance: Consider materialized views or caching for heavy aggregation queries
