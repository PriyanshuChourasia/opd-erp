## 3. Key Database Models

### Appointment Model
```prisma
model Appointment {
  id                 String      @id @default(uuid())
  patientId          String
  doctorId           String
  date               DateTime
  type               String      @default("CONSULTATION")  // CONSULTATION, FOLLOW_UP, WALK_IN
  status             String      @default("SCHEDULED")     // SCHEDULED, CHECKED_IN, IN_PROGRESS, COMPLETED, CANCELLED, NO_SHOW
  tokenNumber        String?
  amount             Int         @default(0)
  registrationFee    Int         @default(0)
  reasonForVisit     String?
  notes              String?
  cancellationReason String?
  createdAt          DateTime    @default(now())
  deletedAt          DateTime?
  // Relations: patient, doctor, bill, queueEntry, patientVitals, history
}
```

model Patient {

### Bill Model
```prisma
model Bill {
  id              String       @id @default(uuid())
  patientId       String?

    where: { createdAt: { gte: start, lt: end } },

  });

```

### Frontend Pattern
```typescript
// hooks.ts
export function useReportData(from?: string, to?: string) {
  return useQuery({
    queryKey: ["reports", "report-name", from, to],
    queryFn: () => fetchReportData(from, to),
    staleTime: 30_000,
  });
}

// api.ts
export async function fetchReportData(from?: string, to?: string) {
  const params = new URLSearchParams();
  if (from) params.set("from", from);
  if (to) params.set("to", to);
  const res = await apiFetch<{ data: ReportData }>(`/reports/endpoint?${params}`);
  return res.data;
}
```
