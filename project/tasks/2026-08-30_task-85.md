## Summary

Implemented the backend database/service query for the Daily OPD Summary report. The report calculates all required metrics using real database data with optimized queries.

## Implementation Details

### Backend Changes

#### 1. Service Method (`apps/api/src/reports/reports.service.ts`)

Added `getDailyOpdSummary()` method that calculates:

**Appointment Metrics:**
- Total appointments
- Completed appointments
- Pending appointments (SCHEDULED, CONFIRMED, CHECKED_IN, IN_PROGRESS)
- Cancelled appointments
- No-show appointments
- Walk-in appointments

**Patient Metrics:**
- New patients (isFollowUp = false)
- Returning patients (isFollowUp = true)

**Revenue Metrics:**
- Total consultation amount
- Total registration amount
- Total amount collected
- Pending amount (total - paidAmount for PENDING/PARTIAL bills)
- Outstanding invoices count

**Rate Metrics:**
- Completion rate
- Cancellation rate
- No-show rate

**Breakdowns:**
- By Doctor (appointments, completed, revenue)
- By Type (count, percentage)
- By Status (count, percentage)
- By Hour (hourly distribution)

#### 2. Controller Endpoint (`apps/api/src/reports/reports.controller.ts`)

Added endpoint:
```
GET /reports/daily-opd-summary?from=YYYY-MM-DD&to=YYYY-MM-DD&doctorId=optional
```

#### 3. Frontend Interface (`apps/clinic-ui/src/modules/reports/data/interface.ts`)

Added TypeScript interfaces:
- `DailyOpdSummaryData`
- `ReportMeta`
- `DailyOpdSummaryResponse`

#### 4. Frontend API (`apps/clinic-ui/src/modules/reports/data/api.ts`)

Added `fetchDailyOpdSummary()` function.

#### 5. Frontend Hook (`apps/clinic-ui/src/modules/reports/data/hooks.ts`)

Added `useDailyOpdSummary()` React Query hook.

## Query Optimization

### Parallel Queries (Avoids N+1)

```typescript
const [appointments, bills, patientCounts] = await Promise.all([
  this.prisma.appointment.findMany({ ... }),
  this.prisma.bill.findMany({ ... }),
  this.prisma.patient.groupBy({ ... }),
]);
```

### Filtering

- Excludes soft-deleted records (`deletedAt: null`)
- Supports date range filtering
- Supports optional doctor filter
- Bills filtered to exclude CANCELLED/REFUNDED

### Indexes Used

- `Appointment.date` (for date range queries)
- `Appointment.doctorId` (for doctor filter)
- `Bill.createdAt` (for date range queries)
- `Patient.createdAt` (for new patient counts)

## Usage Examples

### Get today's summary
```
GET /reports/daily-opd-summary
```

### Get summary for date range
```
GET /reports/daily-opd-summary?from=2026-08-01&to=2026-08-31
```

### Get summary for specific doctor
```
GET /reports/daily-opd-summary?from=2026-08-01&to=2026-08-31&doctorId=abc-123
```

### Frontend usage
```typescript
import { useDailyOpdSummary } from '@/modules/reports/data/hooks';

const { data, isLoading, error } = useDailyOpdSummary(
  '2026-08-01',
  '2026-08-31',
  'abc-123' // optional doctor filter
);

if (data?.success) {
  console.log(data.data.summary.totalAppointments);
  console.log(data.data.summary.totalAmountCollected);
}
```
