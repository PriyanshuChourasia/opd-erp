## Calculation Logic Verification

### Appointment Counts
```sql
-- Database Query
SELECT 
  COUNT(*) as total,
  COUNT(CASE WHEN status = 'COMPLETED' THEN 1 END) as completed,
  COUNT(CASE WHEN status IN ('SCHEDULED', 'CONFIRMED', 'CHECKED_IN', 'IN_PROGRESS') THEN 1 END) as pending,
  COUNT(CASE WHEN status = 'CANCELLED' THEN 1 END) as cancelled,
  COUNT(CASE WHEN status = 'NO_SHOW' THEN 1 END) as no_show,
  COUNT(CASE WHEN type = 'WALK_IN' THEN 1 END) as walk_ins
FROM "Appointment" 
WHERE "deletedAt" IS NULL
  AND date >= CURRENT_DATE 
  AND date < CURRENT_DATE + INTERVAL '1 day';
```

**API Logic:** ✅ Matches database query

### Revenue Calculations
```sql
-- Database Query
SELECT 
  COALESCE(SUM(amount), 0) as total_consultation,
  COALESCE(SUM("registrationFee"), 0) as total_registration
FROM "Appointment" 
WHERE "deletedAt" IS NULL
  AND date >= CURRENT_DATE 
  AND date < CURRENT_DATE + INTERVAL '1 day';
```

**API Logic:** ✅ Matches database query

### Bill Calculations
```sql
-- Database Query
SELECT 
  COALESCE(SUM(paidAmount), 0) as collected,
  COALESCE(SUM(CASE WHEN status IN ('PENDING', 'PARTIAL') THEN "total" - "paidAmount" ELSE 0 END), 0) as pending,
  COUNT(CASE WHEN status IN ('PENDING', 'PARTIAL') THEN 1 END) as outstanding
FROM "Bill" 
WHERE "deletedAt" IS NULL
  AND "createdAt" >= CURRENT_DATE 
  AND "createdAt" < CURRENT_DATE + INTERVAL '1 day'
  AND status NOT IN ('CANCELLED', 'REFUNDED');
```

**API Logic:** ✅ Matches database query

### Patient Counts
```sql
-- Database Query
SELECT 
  COUNT(CASE WHEN "isFollowUp" = false THEN 1 END) as new_patients,
  COUNT(CASE WHEN "isFollowUp" = true THEN 1 END) as returning_patients
FROM "Patient" 
WHERE "deletedAt" IS NULL
  AND "createdAt" >= CURRENT_DATE 
  AND "createdAt" < CURRENT_DATE + INTERVAL '1 day';
```

**API Logic:** ✅ Matches database query
