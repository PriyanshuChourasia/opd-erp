## UI Components

### KPI Cards Displayed

#### Appointments Section
| Card | Value | Variant |
|------|-------|---------|
| Total Appointments | `summary.totalAppointments` | default |
| Completed | `summary.completedAppointments` | success |
| Pending | `summary.pendingAppointments` | warning |
| Cancelled | `summary.cancelledAppointments` | danger |

#### More Metrics Section
| Card | Value | Variant |
|------|-------|---------|
| No-shows | `summary.noShowAppointments` | danger |
| Walk-ins | `summary.walkInAppointments` | default |
| New Patients | `summary.newPatients` | success |
| Returning Patients | `summary.returningPatients` | default |

#### Revenue Section
| Card | Value | Variant | Format |
|------|-------|---------|--------|
| Consultation Amount | `summary.totalConsultationAmount` | default | Currency |
| Registration Amount | `summary.totalRegistrationAmount` | default | Currency |
| Amount Collected | `summary.totalAmountCollected` | success | Currency |
| Pending Amount | `summary.pendingAmount` | warning | Currency |

#### Outstanding
| Card | Value | Variant |
|------|-------|---------|
| Outstanding Invoices | `summary.outstandingInvoices` | warning |

### Charts

1. **By Status** - Status breakdown with badges and percentages
2. **By Type** - Appointment type distribution
3. **Hourly Distribution** - Bar chart showing appointments by hour

### Tables

1. **Doctor Performance** - Doctor ID, appointments, completed, revenue

## Features

### Date Range Selector
- From date picker
- To date picker
- Defaults to today

### States

#### Loading State
```tsx
{query.isLoading && (
  <div className="grid gap-4 md:grid-cols-2 lg:grid-cols-4">
    {Array.from({ length: 13 }).map((_, i) => (
      <Skeleton key={i} className="h-28" />
    ))}
  </div>
)}
```

#### Error State
```tsx
{query.isError && (
  <Card className="border-red-200 bg-red-50 dark:border-red-800 dark:bg-red-950/20">
    <CardContent className="py-6">
      <p className="text-sm text-red-600 dark:text-red-400">
        Error loading report: {query.error?.message}
      </p>
    </CardContent>
  </Card>
)}
```

#### Empty State
```tsx
{!query.isLoading && !query.isError && data && data.summary.totalAppointments === 0 && (
  <Card>
    <CardContent className="py-12">
      <div className="text-center">
        <p className="text-lg font-medium text-muted-foreground">No data for this range</p>
        <p className="text-sm text-muted-foreground mt-1">
          Try selecting a different date range
        </p>
      </div>
    </CardContent>
  </Card>
)}
```
