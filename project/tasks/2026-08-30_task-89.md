### 3. ✅ Refresh data when the date changes

**React Query automatically refetches when query key changes:**

```tsx
// hooks.ts
export function useDailyOpdSummary(from?: string, to?: string, doctorId?: string) {
  return useQuery({
    queryKey: ["reports", "daily-opd-summary", from, to, doctorId],  // ← includes from, to
    queryFn: () => fetchDailyOpdSummary(from, to, doctorId),
    staleTime: 30_000,
  });
}
```

When user changes date pickers:
1. `setFrom()` or `setTo()` updates state
2. Component re-renders with new `from`, `to`
3. `useDailyOpdSummary(from, to)` is called with new values
4. React Query detects query key change
5. Automatic refetch occurs
