## Query Optimization

### Parallel Queries (Avoids N+1)

```typescript
const [doctors, appointments, bills, patientData] = await Promise.all([
  this.prisma.doctor.findMany({ ... }),
  this.prisma.appointment.findMany({ ... }),
  this.prisma.bill.findMany({ ... }),
  this.prisma.appointment.groupBy({ ... }),
]);
```

### In-Memory Processing

Instead of querying per doctor, all data is fetched once and processed in memory:

```typescript
// Build doctor performance map
const doctorMap = new Map<string, { ... }>();

// Process all appointments
for (const appt of appointments) {
  const docData = doctorMap.get(appt.doctorId);
  if (!docData) continue;
  
  docData.totalAppointments++;
  docData.uniquePatients.add(appt.patientId);
  // ... more processing
}
```

### Unique Patient Counting

Uses `Set` to track unique patients per doctor:

```typescript
uniquePatients: new Set<string>();

// When processing appointments
docData.uniquePatients.add(appt.patientId);

// When building report
const uniquePatientCount = doc.data.uniquePatients.size;
```

## Metrics Calculation

### Average Patients/Day
```typescript
const daysInRange = Math.ceil((end - start) / (24 * 60 * 60 * 1000));
const avgPatientsPerDay = uniquePatientCount / daysInRange;
```

### Average Consultation Amount
```typescript
const avgConsultationAmount = totalAppointments > 0
  ? consultationRevenue / totalAppointments
  : 0;
```

### New vs Follow-up Patients
```typescript
// Based on patient.isFollowUp flag
if (appt.patient.isFollowUp) {
  docData.followUpPatients++;
} else {
  docData.newPatients++;
}
```
