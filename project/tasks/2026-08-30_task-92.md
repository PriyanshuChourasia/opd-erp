## Issue Found & Fixed

### Problem: Duplicate Counting of New/Follow-up Patients

**Original Implementation:**
```typescript
// Count new vs follow-up patients per appointment
if (appt.patient) {
  if (appt.patient.isFollowUp) {
    docData.followUpPatients++;  // ❌ Counts per appointment, not per unique patient
  } else {
    docData.newPatients++;  // ❌ Counts per appointment, not per unique patient
  }
}
```

**Issue:** If a patient has 3 appointments with the same doctor, they would be counted 3 times in either `newPatients` or `followUpPatients`.

### Solution: Track Unique Patient IDs

**Fixed Implementation:**
```typescript
// Track unique new vs follow-up patients (avoid duplicate counting)
if (appt.patient) {
  if (appt.patient.isFollowUp) {
    docData.followUpPatientIds.add(appt.patientId);  // ✅ Uses Set for unique tracking
  } else {
    docData.newPatientIds.add(appt.patientId);  // ✅ Uses Set for unique tracking
  }
}

// When building report
const newPatientCount = doc.newPatientIds.size;  // ✅ Returns unique count
const followUpPatientCount = doc.followUpPatientIds.size;  // ✅ Returns unique count
```
