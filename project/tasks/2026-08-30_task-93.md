## UI Components

### Summary Cards

| Card | Value | Subtitle |
|------|-------|----------|
| Total Doctors | `summary.totalDoctors` | `{activeDoctors} active` |
| Total Appointments | `summary.totalAppointments` | `{avgAppointmentsPerDoctor} avg/doctor` |
| Total Revenue | `summary.totalRevenue` | - |
| Total Patients | `summary.totalPatients` | - |

### Revenue Chart

- Horizontal bar chart showing revenue by doctor specialization
- Uses Recharts library
- X-axis: Revenue (formatted as currency)
- Y-axis: Doctor specialization

### Doctor Details Table

| Column | Field | Alignment |
|--------|-------|-----------|
| Doctor | `specialization` + `registrationNo` | Left |
| Total Appts | `totalAppointments` | Right |
| Completed | `completed` | Right |
| Cancelled | `cancelled` | Right |
| No-show | `noShow` | Right |
| New Patients | `newPatients` | Right |
| Follow-ups | `followUpPatients` | Right |
| Revenue | `consultationRevenue` | Right (bold) |
| Avg Patients/Day | `avgPatientsPerDay` | Right |
| Avg Consultation | `avgConsultationAmount` | Right |

## Features

### Date Range Selector
- From date picker
- To date picker
- Defaults to last 30 days

### States

#### Loading State
```tsx
{query.isLoading && (
  <>
    <div className="grid gap-4 md:grid-cols-2 lg:grid-cols-4">
      {Array.from({ length: 4 }).map((_, i) => (
        <Skeleton key={i} className="h-24" />
      ))}
    </div>
    <Skeleton className="h-64 w-full" />
    <Skeleton className="h-96 w-full" />
  </>
)}
```

#### Error State
```tsx
{query.isError && (
  <Card className="border-red-200 bg-red-50 dark:border-red-800 dark:bg-red-950/20">
    <CardContent className="py-6">
      <p className="text-sm text-red-600 dark:text-red-400">
        Error loading report: {query.error?.message}
      </p>
    </CardContent>
  </Card>
)}
```

#### Empty State
```tsx
{!query.isLoading && !query.isError && data && data.doctors.length === 0 && (
  <Card>
    <CardContent className="py-12">
      <div className="text-center">
        <p className="text-lg font-medium text-muted-foreground">No data for this range</p>
        <p className="text-sm text-muted-foreground mt-1">
          Try selecting a different date range
        </p>
      </div>
    </CardContent>
  </Card>
)}
```
