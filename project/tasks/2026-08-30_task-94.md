### 3. ✅ Refresh when filters change

**React Query automatically refetches when query key changes:**

```tsx
// hooks.ts
export function useDoctorWiseOpdReport(from?: string, to?: string) {
  return useQuery({
    queryKey: ["reports", "doctor-wise-opd", from, to],  // ← includes from, to
    queryFn: () => fetchDoctorWiseOpdReport(from, to),
    staleTime: 30_000,
  });
}
```

When user changes date pickers:
1. `setFrom()` or `setTo()` updates state
2. Component re-renders with new `from`, `to`
3. `useDoctorWiseOpdReport(from, to)` is called with new values
4. React Query detects query key change
5. Automatic refetch occurs
