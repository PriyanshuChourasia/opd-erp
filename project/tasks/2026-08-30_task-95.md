## Query Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `from` | string (YYYY-MM-DD) | No | 30 days ago | Start date (inclusive) |
| `to` | string (YYYY-MM-DD) | No | Tomorrow | End date (exclusive) |
| `doctorId` | string (UUID) | No | All doctors | Filter by doctor ID |
| `paymentStatus` | string | No | All statuses | Filter by status: PENDING, PAID, PARTIAL, CANCELLED, REFUNDED |
| `paymentMethod` | string | No | All methods | Filter by method: CASH, CARD, UPI, ONLINE |

## Duplicate Counting Prevention

### Relationship Analysis

- **Appointment → Bill**: 1:1 relationship (Bill.appointmentId is unique)
- **Bill → Appointment**: Optional (standalone bills exist)

### Implementation

```typescript
// Get appointments with their bills (1:1 relationship)
const appointments = await this.prisma.appointment.findMany({
  where: appointmentWhere,
  include: { bill: true },  // At most one bill per appointment
});

// Get standalone bills (without appointments)
const bills = await this.prisma.bill.findMany({
  where: { ...billWhere, appointmentId: null },
});
```

This ensures:
1. No duplicate rows from multiple bills per appointment
2. Standalone bills are included
3. Each transaction appears exactly once

## Usage Examples

### Get report for last 30 days (default)
```
GET /reports/revenue-collection
```

### Get report for specific date range
```
GET /reports/revenue-collection?from=2026-08-01&to=2026-08-31
```

### Get report for specific doctor
```
GET /reports/revenue-collection?from=2026-08-01&to=2026-08-31&doctorId=abc-123
```

### Get only PAID transactions
```
GET /reports/revenue-collection?from=2026-08-01&to=2026-08-31&paymentStatus=PAID
```

### Get only CARD payments
```
GET /reports/revenue-collection?from=2026-08-01&to=2026-08-31&paymentMethod=CARD
```

### Frontend usage
```typescript
import { useRevenueCollectionReport } from '@/modules/reports/data/hooks';

const { data, isLoading, error } = useRevenueCollectionReport(
  '2026-08-01',
  '2026-08-31',
  'abc-123',      // optional doctor filter

  'CARD',         // optional method filter

if (data?.success) {
  console.log(data.data.summary.totalAmount);
  console.log(data.data.rows[0].invoiceNumber);
}
```
