# TASK 96 — Create Revenue Collection API

## Status: ✅ Complete

## Summary

Enhanced the Revenue Collection API endpoint with pagination support and comprehensive aggregate totals.

---

## API Endpoint

```
GET /api/reports/revenue-collection
```

### Query Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `from` | string (YYYY-MM-DD) | No | 30 days ago | Start date (inclusive) |
| `to` | string (YYYY-MM-DD) | No | Tomorrow | End date (exclusive) |
| `doctorId` | string (UUID) | No | All doctors | Filter by doctor ID |
| `paymentStatus` | string | No | All statuses | Filter by status |
| `paymentMethod` | string | No | All methods | Filter by method |
| `page` | number | No | 1 | Page number (1-indexed) |
| `limit` | number | No | 50 | Items per page (max: 100) |

### Examples

```bash
# Get first page of revenue collection
GET /reports/revenue-collection

# Get page 2 with 100 items
GET /reports/revenue-collection?page=2&limit=100

# Get only PAID transactions
GET /reports/revenue-collection?paymentStatus=PAID

# Get only CARD payments for specific doctor
GET /reports/revenue-collection?doctorId=abc-123&paymentMethod=CARD
```

## Aggregate Totals

| Field | Description |
|-------|-------------|
| `totalRows` | Total number of records matching filters |
| `totalRegistrationFee` | Sum of all registration fees |
| `totalConsultationFee` | Sum of all consultation fees |
| `totalOtherAmount` | Sum of all other amounts (standalone bills) |
| `totalBilledAmount` | Sum of all total amounts |
| `totalPaidAmount` | Sum of all paid amounts |
| `totalPendingAmount` | Sum of all pending amounts |

## Pagination

### Request
```
GET /reports/revenue-collection?page=2&limit=25
```

### Response
```json
{
  "pagination": {
    "page": 2,
    "limit": 25,
    "totalPages": 6,
    "totalRecords": 150,
    "hasNext": true,
    "hasPrevious": true
  }
}
```

### Pagination Calculation
```typescript
const skip = (page - 1) * limit;
const paginatedRows = rows.slice(skip, skip + limit);
const totalPages = Math.ceil(totalRows / limit);
```

## Validation Rules

| Rule | Error Message |
|------|---------------|
| Invalid date format | "Invalid date format for 'from' parameter. Use YYYY-MM-DD format." |
| Invalid date range | "Invalid date range: 'from' date must be before 'to' date." |
| Date range > 1 year | "Date range cannot exceed 1 year (365 days)." |
| Invalid doctor ID | "Doctor with ID 'xxx' not found." |
| Invalid payment status | "Invalid payment status. Must be one of: PENDING, PAID, PARTIAL, CANCELLED, REFUNDED" |
| Invalid payment method | "Invalid payment method. Must be one of: CASH, CARD, UPI, ONLINE" |
