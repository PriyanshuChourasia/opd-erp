## UI Components

### Summary Cards

| Card | Value | Color |
|------|-------|-------|
| Total Billed | `summary.totalBilledAmount` | Default |
| Total Paid | `summary.totalPaidAmount` | Green |
| Total Pending | `summary.totalPendingAmount` | Amber |

### Fee Breakdown Cards

| Card | Value |
|------|-------|
| Registration Fees | `summary.totalRegistrationFee` |
| Consultation Fees | `summary.totalConsultationFee` |
| Other Amounts | `summary.totalOtherAmount` |

### Payment Breakdown

#### By Payment Method
- Shows count and amount for each method (CASH, CARD, UPI, ONLINE)

#### By Payment Status
- Shows count and amount for each status (PAID, PENDING, PARTIAL, etc.)
- Uses status badges with appropriate colors

### Detailed Transaction Table

| Column | Field | Alignment |
|--------|-------|-----------|
| Date | `row.date` | Left |
| Patient | `row.patientName` | Left |
| Doctor | `row.doctorName` | Left |
| Reg. Fee | `row.registrationFee` | Right (currency) |
| Consult. Fee | `row.consultationFee` | Right (currency) |
| Other | `row.otherAmount` | Right (currency) |
| Total | `row.totalAmount` | Right (currency, bold) |
| Paid | `row.amountPaid` | Right (currency, green) |
| Pending | `row.amountPending` | Right (currency, amber) |
| Method | `row.paymentMethod` | Left |
| Reference | `row.transactionReference` | Left (mono) |
| Invoice | `row.invoiceNumber` | Left (mono) |
| Status | `row.paymentStatus` | Badge |

### Pagination

- Previous/Next buttons
- Page X of Y (Z records)
- Resets to page 1 when date filters change

## Features

### Date Range Selector
- From date picker
- To date picker
- Defaults to last 30 days

### States

#### Loading State
```tsx
{query.isLoading && (
  <>
    <div className="grid gap-4 md:grid-cols-2 lg:grid-cols-4">
      {Array.from({ length: 6 }).map((_, i) => (
        <Skeleton key={i} className="h-24" />
      ))}
    </div>
    <Skeleton className="h-96 w-full" />
  </>
)}
```

#### Error State
```tsx
{query.isError && (
  <Card className="border-red-200 bg-red-50 dark:border-red-800 dark:bg-red-950/20">
    <CardContent className="py-6">
      <p className="text-sm text-red-600 dark:text-red-400">
        Error loading report: {query.error?.message}
      </p>
    </CardContent>
  </Card>
)}
```

#### Empty State
```tsx
{!query.isLoading && !query.isError && data && data.rows.length === 0 && (
  <Card>
    <CardContent className="py-12">
      <div className="text-center">
        <p className="text-lg font-medium text-muted-foreground">No data for this range</p>
        <p className="text-sm text-muted-foreground mt-1">
          Try selecting a different date range
        </p>
      </div>
    </CardContent>
  </Card>
)}
```
